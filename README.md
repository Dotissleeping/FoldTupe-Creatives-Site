# FoldTupe Creatives
Open `index.html` (or host on GitHub Pages). No build step. Data is kept in the browser's localStorage (per device, not secure: demo only).
- Client: sign up on `#/signup`, then log in. Booking pages require login.
- Admin: `#/admin-login` with admin@foldtupe.studio / admin123. New client bookings appear in Admin > Bookings.
- Reset everything: clear site data in the browser.
